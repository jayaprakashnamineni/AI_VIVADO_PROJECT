WORKED EXAMPLES
============================================================

Example 1 - Wrong signal declaration:

BEFORE (error in Verilog):
```verilog
module counter (
    input wire clk,
    input wire rst,
    output wire count
);
always @(posedge clk) begin
    if (rst) count <= 0;
    else count <= count + 1;
end
endmodule
```
Error: "count" is declared as wire but assigned in always block.

AFTER (fixed):
```verilog
module counter (
    input wire clk,
    input wire rst,
    output reg count
);
always @(posedge clk) begin
    if (rst) count <= 0;
    else count <= count + 1;
end
endmodule
```

Example 2 - Testbench timing race:

BEFORE (error in testbench):
```verilog
always @(posedge clk) begin
    count_prev <= count;
end

initial begin
    // ...
    @(posedge clk);
    if (count !== expected) begin // CHECKING AT SAME EDGE - RACE!
        $display("SIMULATION FAILED");
        $finish;
    end
end
```
Error: Checking output at exact same ns as clock edge causes race condition.

AFTER (fixed):
```verilog
initial begin
    // ...
    @(posedge clk);
    #1; // WAIT 1ns FOR PROPAGATION
    if (count !== expected) begin
        $display("ASSERTION FAILED");
        $display("CHECK: Counter value after clock edge");
        $display("TIME: %0t", $time);
        $display("EXPECTED: %0d", expected);
        $display("ACTUAL: %0d", count);
        $display("SIMULATION FAILED");
        $finish;
    end
end
```

Example 3 - Wrong expected value in testbench (MINIMAL FIX):

BEFORE (error in testbench only - RTL is correct):
```verilog
// Test counting with enable
en = 1;
#160; // 16 clock cycles
if (count !== 4'b1000) begin
    $display("ASSERTION FAILED");
    $display("CHECK: Counter should reach 8 after 16 cycles");
    $display("TIME: %0t", $time);
    $display("EXPECTED: 8");
    $display("ACTUAL: %d", count);
    $display("SIMULATION FAILED");
    $finish;
end
```
Error: Expected value 8 is wrong. A 4-bit counter with en=1
for 16 clock cycles: 16 mod 16 = 0. The counter wraps to 0.

RTL is correct. Only the testbench expected value is wrong.

AFTER (minimal fix - only the incorrect lines changed):
```verilog
// Test counting with enable
en = 1;
#160; // 16 clock cycles
if (count !== 4'b0000) begin
    $display("ASSERTION FAILED");
    $display("CHECK: Counter should wrap to 0 after 16 cycles");
    $display("TIME: %0t", $time);
    $display("EXPECTED: 0");
    $display("ACTUAL: %d", count);
    $display("SIMULATION FAILED");
    $finish;
end
```

Changed lines only:
- Line 3: 4'b1000 -> 4'b0000 (correct expected value)
- Line 5: "reach 8" -> "wrap to 0" (matching message)
- Line 7: "EXPECTED: 8" -> "EXPECTED: 0" (matching value)

RTL is preserved byte-for-byte. Testbench structure, clock
generation, reset sequencing, and all other checks are
unchanged.
